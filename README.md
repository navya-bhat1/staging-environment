# Project: Staging Environment Deployment

## Purpose
Fully automated AWS staging environment for testing and deployment.

## AWS Services Used
EC2, S3, ECS, Lambda, CloudWatch, Terraform

## Responsibilities
- Designed multi-AZ VPC with public/private subnets
- Automated infrastructure deployment using Terraform
- Configured ECS services and CI/CD pipelines using GitHub Actions
- Monitored applications with CloudWatch

## Achievements
- Reduced deployment errors by 90%
- Implemented zero-downtime staging environment
- Streamlined CI/CD process for faster releases
